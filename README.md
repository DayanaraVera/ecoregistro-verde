# EcoRegistro Verde

Crea una aplicación web responsive y moderna para el proyecto "EcoRegistro", con el subtítulo "Tecnología para cuidar el medio ambiente" y vinculada a la visualización interactiva desarrollada en Visual Basic del equipo de Dayanara Vera, Jessica Carpio y Tifanny Cano (3.º de Bachillerato Técnico en Informática — 3.º BTI, fecha: 20/11/2026).

No inventes información, datos estadísticos, métricas ni textos adicionales que no estén indicados aquí.

1. Arquitectura y secciones (HTML5 semántico):
- Encabezado (Header): muestra el título principal "EcoRegistro", el subtítulo "Tecnología para cuidar el medio ambiente", un logotipo/identidad visual tecnológica y una breve explicación del proyecto y su visualización en Visual Basic.
- Panel / bloque central de contenido: incluye el botón principal con el texto "Ver visualización" (o "VER VISUALIZACIÓN") configurado con su evento de clic/enlace hacia el destino "C:\Users\ferna\OneDrive\Escritorio\DAYANARAVERA" (archivo .exe de Visual Basic). Incluye un elemento de aviso visible (span o alert) que informe al usuario si el enlace o recurso no está disponible o no puede abrirse, evitando que el botón parezca no funcionar.
- Bloque lateral junto al contenido principal: muestra un mapamundi (recurso gráfico/imagen) ubicado al lado del contenido principal, con una animación suave y sin dificultar la lectura.
- Sección de infografía: incluye un contenedor/sección clara y dedicada para mostrar la infografía del proyecto (lista para cargar o mostrar el recurso gráfico de la infografía) La infografia te adjunto.
- Pie de página (Footer): muestra los créditos del equipo (Dayanara Vera, Jessica Carpio y Tifanny Cano — 3.º BTI) y una indicación/enlace para regresar a la página principal.

2. Estilo visual, paleta de colores y tipografía:
- Fondo general oscuro (#071A12, verde noche / casi negro) con un fondo estrellado de estrellas pequeñas / animadas (CSS, PNG o SVG) y estilo tecnológico/espacial con tarjetas de bordes redondeados y efectos luminosos moderados.
- Color primario: #059669 (verde esmeralda) para el botón principal, títulos destacados y detalles luminosos.
- Color secundario: #34D399 (verde menta) para bordes, enlaces, detalles del mapamundi y elementos interactivos.
- Texto y contraste alto: #F0FDF4 (blanco verdoso) para títulos, etiquetas y textos legibles.
- Tipografías: Orbitron, Montserrat y Poppins.
- Diseño totalmente adaptable (responsive) para computadoras y celulares.
